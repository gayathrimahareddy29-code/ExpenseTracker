# Expense Tracker

A simple console-based Expense Tracker application built using Java.

## Features

* Add expenses
* View all expenses
* Calculate total expenses
* Delete expenses
* Categorize expenses
* Menu-driven interface

## Technologies Used

* Java
* ArrayList
* Scanner
* Object-Oriented Programming

## Java Concepts Used

* Classes and Objects
* Constructors
* Methods
* ArrayList
* Loops
* Switch statements
* Conditional statements
* User input

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac ExpenseTracker.java
```

5. Run the program:

```bash
java ExpenseTracker
```
